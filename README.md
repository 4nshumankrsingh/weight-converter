# ⚖️ Weight Converter Program (Java)
This is a simple Java console application that converts weights between Kilograms and Pounds using an intuitive menu-driven approach.

What It Does:
- Converts Kilograms to Pounds
Formula: lbs = kg × 2.205
- Converts Pounds to Kilograms
Formula: kg = lbs ÷ 2.205
- Handles invalid menu options with an appropriate message.
